**其十　@吱吱教主**

> 我一直好奇国人觉得龙是祥瑞，但西方龙代表邪恶。基督教在《圣经》中，龙常被直接描绘成魔鬼撒旦的化身，都被塑造成代表七宗罪的邪恶符号。这种邪恶形象其实有更古老的源头，早在巴比伦神话中，龙就象征混沌，混乱与毁灭，英雄神必须杀死龙才能创造世界。基督教继承了这一逻辑，将龙踩在脚下，以此象征打败异教，建立新秩序。英雄击败混沌之龙（提亚马特）以创造秩序"的经典情节，正是出自这一时期著名的创世史诗《埃努玛·埃立什》。梵蒂冈是基督教的重要中心而巴比伦人在写《埃努玛·埃立什》的时候，中国正处于夏朝中后期。然后上古音联想一下就是hwaŋ-t'iʔ-koŋ皇帝宫，把上古音 hwaŋ-t'iʔ-koŋ 连读快一些hwaŋ → 近似 "梵"（轻唇化后为 fan）t'iʔ → 短促的 "蒂" 或 "提"koŋ → 明显的 "冈"这巧合有趣的地方在于，夏代"皇帝宫"可能的上古读音，竟与后世罗马教廷所在地的汉译名重合，仿佛两个文明在声音上产生了跨时空共振。夏朝人信奉神明，尤其是天神上帝 和祖先神。他们相信天神上帝支配自然，祖先能传话，国家大事必须通过隆重祭祀来决定。夏代还没有后世"皇帝"的概念。
