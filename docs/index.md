# 丙午稗史

<div class="lead">世有奇谈，姑录其言；真伪未定，留待后贤。</div>

丙午岁，网络间流传种种历史异说，或据谐音重订古今，或凭想象迁移山河，或将未经核验的阴谋传闻奉为信史。本编以九卷分类存录，意在观察与考辨这种网络现象，**绝不认同书中引述的歧视、仇恨与暴力主张**。
