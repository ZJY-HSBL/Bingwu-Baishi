# 丙午稗史 · Bingwu-Baishi

> 世有奇谈，姑录其言；真伪未定，留待后贤。

《丙午稗史》是一部记录、分类与考辨**2026年前后网络伪史言论**的开放式文献集。全书采用文言序跋与九卷体例，初编收录 **73则**网络言论。

**重要说明**：本项目保留部分可能令人不适的原始引文（包括虚假指控、族群歧视及暴力表述），目的在于观察和批判网络谣言与伪史叙事。**引述不代表赞同，也不构成对被引述言论的真实性背书。** 署名根据样本记录，未经逐条独立验证。

## 文献原则

- 按来源样本保留文字，明确区分**引文**与**编者立场**。
- 未经核验的归属、数字与叙事不作为史实。
- 适时补充来源、反证、版本校订与考辨注释。
- 本项目不鼓励针对任何群体的仇恨、歧视或暴力。
